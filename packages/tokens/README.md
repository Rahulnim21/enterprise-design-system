# @enterprise/tokens

This package contains the design tokens for the Enterprise Design System. It serves as the single source of truth for all stylistic values, such as colors, spacing, typography, and more.

## Generation

Tokens are generated from a source file (e.g., from Figma Tokens Studio) and transformed by Style Dictionary into multiple formats (CSS, JS, iOS, Android, etc.) for consumption across all platforms.

To generate the tokens, run the build script from the root of the monorepo.
